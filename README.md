# PokéScan

App Android: escaneia cartas de Pokémon TCG com a câmera (OCR offline via ML Kit), valida na API pokemontcg.io e monta uma Pokédex de cartas, com progresso por set, quantidades e valor em várias moedas.

Cada push na `main` gera um APK assinado e publica uma Release; o app se atualiza sozinho a partir dela.
